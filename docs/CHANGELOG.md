# 0.113.0 — Old Stonewright’s Rise

Adds optional provisional household use after the first paid shift, with Ivar’s saved in-world introduction. Two contributions still grant permanent tenure, upgrading the same property without resetting construction, storage or development. Existing permanent owners retain their rights and property names. Regression coverage extends frontier103 for locality, eligibility, scene reload/skip and ownership continuity.
