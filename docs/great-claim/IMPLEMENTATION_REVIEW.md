## Concrete integration gaps found in code

1. **The current story has no exit into its next chapter.** `frontier103.gd` initializes `keldrath_open=false`; `surface.gd` enforces it. No script currently sets it true. This is consistent with an unfinished chapter boundary, not a completed new introduction.
2. **The tie is recorded once but the live player score can continue rising.** Authentication in `mountain104.gd` records work/rival totals and awards their difference. `great_claim102.gd` still credits subsequent work/contributions, while authenticated standings freeze Skarrin's score and display the player's current total. Before building the tiebreaker, define a closed contest-round score separately from later useful-work credit and test continued work after authentication. This is a code-review finding; no new runtime reproduction is claimed here.
3. **Remaining bespoke world bundles need activity coverage.** The subsequent Dagna pass adds explicit drink routing and enables her reviewed idle/walk/drink set; her current roles are host and rescue victim, not recruitable worker. Other named characters can work and, in Borin’s case, fight. Those bundles still need the corresponding whole art and routing before activation. Unsupported future actions retain their functional renderer rather than silently turning into idle.
4. **Relationship and continuity data need later payoffs.** Saved Skarrin insights, partner selection, home construction and inventories already exist. Later chapters must consume those records, preserve them across retries/saves, and visibly honor them; adding new story flags alone will not satisfy that requirement.

## Recommended implementation order

1. **Finish the already-authorized art milestone.** One consistent four-view whole-character gait, sustainable idles and every reachable activity must pass native-scale visual review before expanding/activating the cast. Then verify portraits and world identities together, save continuity and exported resources. Dagna has subsequently passed this gate; the remaining cast has not.
2. **Finish the contest and Keldrath chapter.** First settle score closure; build the physical skill challenge, victory, offer/refusal, invitation and travel. Preserve belongings and allow city exploration before the ceremony. Test interruptions, repeat interactions and reloads.
3. **Implement invasion and trial as playable encounters.** Add reliable loss/retry and save boundaries, reachable civilians, both duel responses, royal intervention/return and the fixed verdict with meaningful player opinions. Do not replace the battle with text summaries.
4. **Implement return and governing.** Compare the same frontier save before and after appointment, retaining homes, excavations, goods and relationships. Expand the ledger into physical projects and staffing while keeping personal work relevant.
5. **Complete household and cast depth alongside those chapters.** Marriage/cohabitation, personal quests, routines and chapter reactions need actual world presence. Finish cinematic/audio work and a complete opening-to-Thane playthrough before calling the directive delivered.

The main path is built through rescue/authentication. The remaining work includes several major gameplay chapters, not just finishing dialogue or polishing art. No percentage estimate is assigned: the implementation sizes differ substantially.
