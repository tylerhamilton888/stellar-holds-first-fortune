# Start in Stonebridge

Extract the complete Windows ZIP into a folder and open the game executable. Choose New Game, an empty slot and a dwarf. Use Load Game for an existing Stonebridge Campaign save.

Use WASD to walk and E to interact. Try Ivar’s walk to the Rise, Borin’s cold forge or the Ledger Shrine across the street. Press I for the pack and J for the journal. When testing inventory, search for a material, switch between carried items and the catalogue, and pin a supply to a quick-bar slot. Escape closes the page.

For deeper testing, check building placement at the cottage, walking indoor ramps, mining beneath the holding and returning through the same entrance. Reload midway through the introduction or after making a change at home.
