# Art assets in 0.38.0

Created with the built-in image-generation tool. Images were generated as game assets, copied into the project and inspected in native Godot captures. Transparent sprite alpha is retained. The procedural collision boundaries, maps, labels and interfaces are authored in code; the painted maps are scenery.

## Files

- `assets/royal-v39/eirik.png`: unique standing world sprite. Reference inputs were `assets/opening-v31/lord-eirik.png` for identity and `assets/actors-v36/male0-normal-0.png` for the in-game proportions/style.
- `assets/hold-v39/hearthward.png`: residential district plate.
- `assets/hold-v39/crownward.png`: royal district variant, using Hearthward as the layout reference.
- `assets/hold-v39/forgeward.png`: industrial district variant, using Hearthward as the layout reference.
- `assets/hold-v39/expedition-table.png`: transparent table prop used on the concourse and at the mine entrance.
- `assets/hold-v39/workings-valley.png`: isolated mountain backdrop, with no hold gate.
