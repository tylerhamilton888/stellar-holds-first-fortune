# Personal development — implemented foundation and next steps

The 0.65.0 source implements Mining, Smithing, Masonry, Forestry, Woodworking, Brewing, Farming, Fishing, Gathering, Runecarving, Warrior, Overseer and Engineer tabs. Brewing is a reserved path awaiting its production loop. Twelve paths earn completed-work credit; thirteen learnable techniques and eight existing research methods have real gameplay consequences. See testing/disciplines71.md.

Preserve the distinction between personal mastery, discovered knowledge and civic standing. Next expansion: a dedicated brewing station and production, deeper craft quality/precision options, practical apprenticeships, and meaningful new abilities tied to finished systems. Avoid every-swing XP, dismantle/rebuild XP farming, arbitrary mandatory gates for basic conveniences, or noble titles improving tool damage. Existing progress must survive each expansion. No respecialization cost is needed yet because techniques are cumulative and learning does not consume XP.
