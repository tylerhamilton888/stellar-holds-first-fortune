# Upright workshop props

Five original sprites created with the built-in image-generation editor, using
`assets/animation-v51/workshop.png` as the object/style reference. Exact prompts,
reference and transparent-background settings are recorded in `production.json`.
Generated PNGs are copied intact; the historical atlas remains available.

Stonebreaker, sawbench, stone stockpile, timber stockpile and materials pallet
have horizontal front edges and upright supports. `HoldHandworks.texture` trims
transparent margins at runtime and supplies the same artwork to live equipment,
placement previews and the crafting board. Carts, wagons, raw-load drawings and
approved whole-character frames retain their sources.

Native review covers empty and loaded equipment, stonebreaking and sawing,
single/double shoulder loads, underground cargo and the equipment board at
1280×720. Verification and remaining limitations: `docs/testing/work76.md`.
