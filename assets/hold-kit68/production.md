# Hold of Three Hearths — original environment art

Created for this project using image generation on 2026-10-21, with the existing hold-kit67 masonry as the style reference. Exact prompts accompany the source images. Original outputs are retained unchanged; runtime uses measured atlas crops, scaling and tint. No downloaded game assets are used.

- civic.png: transparent six-cell original atlas, 1536 × 1024. SHA-256 aaae55a308c761956332317c16aa91edcf5289234ac3a35341a5cbc0fdcedffb.
- works-below.png: original distant mountain architecture painting, 1536 × 1024. SHA-256 fe0b1fce7d53511db6ac9fbb0fb826cbafb28e950963950827d32b12014099db.

HoldCivicArt defines measured crops and exit leaf collision. HoldFurnishings owns the shared build catalogue and prop footprints. HoldWardDesign owns authored activity pockets, cached paving and distant scenery. The background is intentionally non-playable and is behind the solid playable perimeter; it is not a collection of promised entrances. Pressure machinery is decorative, while existing freight chests provide actual storage.
