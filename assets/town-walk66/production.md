# Town walk passing poses

NPC-only whole-character side-walk passing keys, generated from the existing whole-v58 identities. Runtime uses existing contact poses, the two drawn passing poses, and the canonical hair/skin/cloth palette. Player art and frame selection are unchanged. No separated limbs, head overlays, rotating parts, or added tools.

All fourteen identities retain their original core frames in other directions. Female5 uses the accepted right-facing passing pose for both passing beats; the other candidate faced front and is not selected. Original source art remains untouched.
