# Hearth & Stone surfaces

Original artwork created for this project using the built-in image-generation tool. No external game assets. The unmodified atlas is divided into four equal quadrants: mountain bedrock, roof slate, teal woven rug, burgundy woven rug. Runtime crops use half the actual texture dimensions, avoiding assumed export resolution. Earlier assets are retained.

Production prompt:

Create one original production texture atlas for The Stellar Holds, a charming illustrated Dwarven mountain-hold game. Four exact equal square quadrants in a 1024x1024 square image, no gaps, no labels, no text. Top left quadrant: seamless dark blue charcoal mountain bedrock texture, bold hand-painted angular crags, deep crevices, sparse muted warm ochre mineral seams, substantial irregular stones, not regular bricks. Top right quadrant: seamless dark petrol teal SLATE ROOF shingles with clear overlapping bevelled stone courses and restrained weathering, regular staggered shingles, lighting upper left, readable illustrated strokes. Bottom left quadrant: an entire rectangular teal woven Dwarven rug viewed perfectly straight overhead, warm cream angular knot border, subtly textured woven center, narrow fringe all four sides, flat dark teal background filling the quadrant right to its edges. Bottom right quadrant: same cohesive rug design but warm burgundy and ochre, no symbols or text, perfectly overhead. Style all four: warm hand-painted cartoon game art with confident dark outlines and softly painted bevels, substantial traditional Dwarven craftsmanship, neither pixel art nor photo, consistent with illustrated stocky Dwarf sprites. Flat material maps without perspective vanishing points, no objects, no characters, no room, no furniture, no highlights that resemble gloss. These will be mapped directly to in-game geometry. The upper textures must fill their entire exact 512x512 quadrants. No panels, frames or separators between quadrants.
